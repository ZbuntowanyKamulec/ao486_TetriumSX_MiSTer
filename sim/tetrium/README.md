# SoC simulation (Verilator)

The whole SoC (`rtl/system.v` with Tetrium and the L2 cache) with a DDR3 model and the HPS side
(BIOS images, CMOS, floppy, IDE from a .vhd image), and an SDL window for the VGA output and the
PS/2 keyboard. Sound, GUS, UARTs and MPU-401 are stubs. Needs Verilator 5 (tested with 5.020)
and SDL2. Run from the repository root.

```sh
sim/tetrium/build.sh [threads]          # -> build/sim/Vsoc_sim (default 1 thread)
WIN=1 sim/tetrium/build.sh [threads]    # -> build/winsim/Vsoc_sim.exe (MinGW cross build)
build/sim/Vsoc_sim [-hd dos.vhd] [-rom dir] [-mhz N] [-nowin] [-cycles N] [-shot out.ppm]
```

| Option | |
|---|---|
| `-hd image` | IDE 0-0 from a .vhd image |
| `-rom dir` | `boot0.rom` / `boot1.rom` (default `releases`) |
| `-mhz N` | clk_sys for the SoC's clock_rate (default 33.33) |
| `-cdiv N`, `-cdivsw C` | CPU clock clk_sys / 2^N; step the divider every C cycles |
| `-shot f.ppm`, `-shotevery S` | screenshot at exit; `live.ppm` every S sim seconds |
| `-enter T`, `-type T "text"` | press Enter / type text at sim time T s (`\n` = Enter) |
| `-save T file`, `-load file` | save / restore the whole state (same build only) |
| `-ide`, `-trace` | trace IDE port I/O / retired instructions |

MS-DOS 6.22 with HIMEM, EMM386 and a mouse driver reaches the prompt at about 8 s sim time
(Linux, one thread: about 150 kHz). BIOS debug output (port 8888h) and POST codes (port 80h)
go to the terminal. A memory checker compares every CPU read beat with a reference copy of RAM
(below A0000h and 1-16 MB) and prints a summary at exit. On a CPU shutdown the testbench prints
the last exceptions and retired instructions, the registers, and writes `shutdown.mem`.

The Windows build needs the SDL2 MinGW devel package (SDL2-devel-2.30.9-mingw.tar.gz) unpacked
in `build/winsim/dl`, and reads `ucode_rom.hex` from its working directory: run it from a
folder with the exe, `ucode_rom.hex`, `boot0.rom` and `boot1.rom` (`-rom .`).

Simulation-only details:

- `simfix.py` makes sim copies of `system.v`, `vga.v`, `rtc.v` and `joystick.v`: Verilator
  5.020 re-runs initialisers of regs declared inside always blocks, and lets other blocks see
  blocking assignments in clocked blocks in the same cycle.
- clk_vga runs at 2x clk_sys (the VGA text pipeline needs gaps between pixel enables).
- The HPS (mgmt bus) strobes have a low cycle between accesses: `ide.v` and `floppy.v` step
  their buffer address on the strobe's falling edge.
- The PS/2 mouse answers like Main_MiSTer (no movement): the BIOS waits for mouse replies
  without a timeout.
- `stubs.v` is generated by `mkstubs.py`; `simlib.sv` models the Altera RAM primitives.
